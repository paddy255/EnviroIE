# EnviroIE Reader

This document serves as a guide for reading and understanding the EnviroIE project.

## Project Overview

EnviroIE is a Spring AI powered RAG (Retrieval-Augmented Generation) chatbot designed to answer natural language questions about Irish environmental data. The project runs on a local Ollama model to minimize carbon footprint and represents a unique intersection of enterprise Java architecture, agentic AI, and environmental data science.

## Key Features

- **Spring AI Integration**: Leverages Spring AI framework for AI capabilities
- **RAG Architecture**: Uses Retrieval-Augmented Generation for accurate, context-aware responses
- **Local Model Execution**: Runs on Ollama for reduced environmental impact
- **Irish Environmental Data**: Specialized for Irish environmental information
- **Enterprise Java Stack**: Built with enterprise-grade Java architecture
